# Putting Wealth on the Map

*Our work with the Open Wealth Consortium, and where it goes next* · October 2026

A 15-minute talk by Liz Morrell and Kailas Venkitasubramanian (UNC Charlotte Urban Institute).
It covers the Charlotte metro's local wealth profile from the Open Wealth Consortium, county-level
research on the wealth–income mobility gap across the 14-county Charlotte region, and where this
work could fit in the Carolinas Regional Explorer.
